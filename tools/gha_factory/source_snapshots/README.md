# Public GHA snapshot foundation — gated

This code is an **offline staging and security foundation**, not a production corpus ingestion or release pipeline. Source rights are solely approved by Route 05/GHA-01. The existing public ledger has no approved sources. GHA-02 currently recognizes only registry and admission-partition verification tasks, not source snapshots. **BLOCKED_SOURCE / BLOCKED_DEPENDENCY_GHA02**.

The command `python3 -m tools.gha_factory.source_snapshots.processor stage-local --repo-root . --source-id ID --language de --dataset-version VERSION --expected-size VERIFIED_BYTES --snapshot /absolute/verified/input.jsonl.gz --output /absolute/scratch/output --format jsonl.gz` requires an already-approved source. It verifies immutable input SHA-256/size, source-specific license evidence, version and canonical language; streams JSONL (plain/gzip/bzip2/xz) in bounded reads, records malformed row hashes without corrections, shards by canonical order, and atomically publishes local *STAGED_ONLY* receipts. It never generates lexical content, opens private repo data, touches packs/manifests, enqueues tasks or commits large archives.

The separate `download` function enforces reviewed HTTPS host, public DNS, TLS verification, rejects redirects, streamed fixed-size Range resume, SHA-256 and bounded retries. It is intentionally **not exposed for production** until the queue owner supplies an authenticated immutable lease and reviewed expected byte count. A local checkpoint is not a GHA-02 durable checkpoint; ephemeral runner disks do not survive cancellations.

The manual-only GitHub workflow runs synthetic tests and prints explicit blockers. No schedule is enabled until GHA-02 supports snapshot task types, per-source/language/shard claims and durable checkpoint receipts, and GHA-01 supports external immutable source handoff without storing huge archives in Git. Production worker configuration must use standard `ubuntu-latest`, `max-parallel: 3`, and individual timeout ≤300 minutes, never inventing GitHub run IDs. There is no automatic release/redistribution. The current production counts and SHA are **zero/unavailable**.
